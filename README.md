# 파랜드 택틱스 2 웹 리메이크

1998년 PC 게임 **파랜드 택틱스 2**를 브라우저에서 원작 그대로 플레이한다. 오프닝부터 엔딩까지 18 스테이지, 33 전투, 원작 세이브 호환.

## 게임 실행

Node.js 22.12 이상(npm 포함)만 있으면 된다. 게임 자료는 저장소에 들어 있다.

```bash
git clone https://github.com/sky629/farland-tactics.git
cd farland-tactics/web
npm install
npm run dev
```

브라우저에서 **http://localhost:5173/play.html** 을 연다. 끝낼 때는 터미널에서 Ctrl+C.

## 게임 방법

### 시작

1. 타이틀 화면에 **데이터 선택** 창이 뜬다. **처음부터**를 누르면 새 게임이다.
2. 이어서 하려면 슬롯을 고르고 **결정**을 누른다. 원작 게임의 세이브 파일(`save00.dat`~`save31.dat`)은 **가져오기…**로 넣을 수 있다.
3. 소리는 첫 클릭 뒤부터 난다(브라우저 정책).

### 대화와 마을

- 대사는 **클릭** 또는 **Enter**로 한 줄씩 넘긴다.
- 마을에서는 불이 켜진 시설을 **클릭**한다. 처음에는 여관과 길드가 열려 있다. **오른쪽 클릭**을 하면 이동할 수 있는 시설 목록과 시스템 메뉴가 뜬다.
- 상점에서는 물건을 고르고 **사기**를 누른다. 장비는 가방이 빈 파티원에게 들어간다. 팔 때는 **유니트 일람**의 **도구** 탭에서 물건을 오른쪽 클릭한다.
- 여관에서 하루를 마치면 다음 이야기로 넘어간다.

### 전투

1. 파티원을 **왼쪽 클릭**하면 이동 범위가 보인다. 칸을 클릭하면 이동하고, 적을 클릭하면 공격한다.
2. 파티원을 **오른쪽 클릭**하면 마법·특기와 도구를 쓸 수 있다.
3. 제자리를 클릭하면 방향을 정하고 대기한다. **Esc** 또는 오른쪽 클릭은 한 단계 취소다.
4. 모두 행동했으면 **턴 종료**(F10 또는 0)를 누른다. 적 턴이 지나면 다시 내 턴이다.
5. 쓰러진 파티원은 다음 전투에서 HP 1로 돌아온다. 패배하면 게임 오버 화면 뒤 타이틀로 돌아간다.

### 저장과 불러오기

- **저장하기**(F5 또는 5)는 마을과 전투 중 언제든 된다. 슬롯은 32개이고 브라우저 안에 남는다.
- 자동 저장: 전투 시작 때 슬롯 30, 매 턴이 끝날 때 슬롯 31.
- **불러오기**(F1 또는 1)에서 **내보내기**를 누르면 원작이 읽을 수 있는 세이브 파일을 받는다.

### 키

| 키 | 동작 |
|---|---|
| F1 또는 1 | 불러오기 |
| F2 또는 2 | 유니트 일람 (능력·장비·마법·도구) |
| F3 또는 3 | 전체 맵 (전투 중) |
| F4 또는 4 | 전체 화면 |
| F5 또는 5 | 저장하기 |
| F6 또는 6 | 배속 1배 → 2배 → 4배 (메뉴 바 오른쪽의 **배속** 표시를 눌러도 된다) |
| F10 또는 0 | 턴 종료 |
| F11 또는 9 | 환경설정 (전체 화면·효과음·배속) |
| Enter | 다음 대사 |
| Esc | 취소, 창 닫기 |
| 방향키, 드래그 | 전투 화면 스크롤 |
| Shift | 앞을 가리는 물체 투시 |

메뉴 바의 `맵` 메뉴에서도 같은 기능을 쓸 수 있다.
