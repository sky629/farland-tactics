## 3. 마을 화면 (모드 9) [관찰 `FUN_0042b080`, `FUN_0042ad70`, `FUN_0042ac90`]

### 3.1 배경 레이어

`bmp\Town%02d.bmp`, 번호 = 세트 베이스 + 레이어. 세트 베이스: 1 → 0, 2 → 10, 3 → 20 (`EXT TOWN_SET`, `FUN_0042ac90`; `FUN_0042ad70` 은 어둠 플래그 `DAT_0044b268` → 20, 밤 플래그 `DAT_0044b260` → 10, 아니면 0). 레이어 수는 밤 플래그와 `DAT_0044b264`(TOWN_EXTRA)가 모두 켜졌을 때만 5, 아니면 4 — 즉 레이어 4 는 **세트 2 전용**(파일도 `town14` 만 있음). 레이어:

| 레이어 | 용도 | 그리기 |
|---|---|---|
| 0 | 전체 배경 640×480 | (0,0) |
| 1 | 112×64 프레임 시트 (224×192 = 2열 × 3행) | 프레임 `k = DAT_0044b4f0 / 3` (0..4): 원본 rect (k/3·112, k%3·64) → 화면 (528, 0) |
| 2 | 288×160 프레임 시트 (576×480) | 같은 k: (k/3·288, k%3·160) → 화면 (352, 320) |
| 3 | 시설 하이라이트 | 하이라이트가 켜진 시설(`DAT_0044b1c0[i]`)의 하이라이트 rect 를 같은 좌표로 복사(`DAT_0044b27c` 가 0 이 아닐 때) |

레이어 1~4 의 투명색 [관찰 `FUN_0042ad70` 0x42ae4d]: 시트를 만든 뒤 `FUN_00418c20(surface, 0, 8, &key)` 로 **(0, 8) 픽셀**의 팔레트 인덱스를 읽어 `FUN_00419050`(SetColorKey)에 준다. 실제 값: `town01/02/11/12/21/22` → 249(빨강), `town03/13/23`(하이라이트) → 255(흰색), `town14` → 32. 레이어 0 은 불투명.
| 4 | 128×128 프레임 시트 (384×256, 세트 2 + `TOWN_EXTRA`) | `j = DAT_0044b4f4 < 11 ? 5 − |DAT_0044b4f4 − 5| : 0` (0→5→0 뒤 프레임 0 으로 쉼): (j%3·128, j/3·128) → 화면 (496, 160) |

카운터 [관찰 `FUN_0042b740`]: 레이어 0 이 로드된 뒤에는 **직전 틱에서 50 ms 를 넘겼을 때만** 두 카운터가 함께 1 씩 는다(60 fps 에서는 실질 약 67 ms). `DAT_0044b4f0 = (+1) % 15`, `DAT_0044b4f4 = (+1) % 30` 인데 값이 2 또는 4 가 되면 1 을 더 더한다(0,1,3,5,6,…,29 의 28 값 주기). 웹판 `town.ts` 는 틱 50 ms 로 모델링한다. 레이어 0 은 팔레트 0x20..0x70 을 공유 팔레트로 쓴다(`FUN_00434250`, `FUN_004182e0`).

## 4. 필드(전투) 컨트롤러 (모드 1) [관찰 `FUN_004332f0`]

## 5. 행동 결과 처리와 스크립트 훅 [관찰 `FUN_0043a2e0`]

단계(`DAT_0046178c`): 2 효과 애니 종료 대기 → 3 1초 뒤 효과 해제 → **4 대상마다 라벨** → 5 쓰러진 적 처리(status 1, 페이드) → 6 피격 애니 종료 대기 → 7 경험치 계산 → 8 경험치 바 연출(레벨업 효과음) → 9 드롭 전환·`levelup%02d` → 10 승패.

- 단계 4, 대상 t 마다 (`DAT_0046cc48` = 행동 유닛 a, `DAT_0046cb1c` = t, 스크립트의 유닛 24):
  - t.id ≠ 8 이면: (t == a 또는 a 없음 또는 a.side ≠ 0 또는 t.side ≠ 0) → `BEAT%02d`(t.id) if t.status == 1 else `AFTER%02d`(t.id); 그 외(둘 다 파티, 다른 유닛) → `ASSIST%02d`(a.id). 라벨이 stage 파일에 있으면 실행하고 이 대상은 끝.
  - 그 뒤 t.status == 1 이고 a.side == 0 이면 `WIN%02d`(a.id).
- 단계 7 경험치: 대상마다 `exp_value·dmg/hpMax (+exp_value 처치) ×2(id≠8)` 에 레벨 차 보정, 메시지 대상은 7,3,1 계열 — `battle_rules.md` §5.1 과 같다.
- 단계 9: 드롭이 있는 시체는 진영 7 오브젝트(race 8 아이템/9 골드), 없으면 id 8·id>30 시체 삭제; 레벨업 횟수만큼 `FUN_0041f7c0` 성장 후 `levelup%02d`(a.id)를 **EVENT00** 에서.
- 단계 10: 파티에 행동 가능 유닛이 없으면 `GAMEOVER`(EVENT00); 적(side ≠ 1, 7, status ≠ 9, HP > 0)이 없으면 `COMPLETE`(stage).

행동 전 `battle%02d`(`FUN_0043af00`): 대상 목록의 첫 적대 유닛에 대해 id = 대상 id (대상 side ≠ 0) 또는 행동 유닛 id 로 라벨을 찾고, 있으면 스크립트가 연출을 대신한다(`END_RESUME` 로 복귀).
