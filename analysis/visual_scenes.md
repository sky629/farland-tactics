# 비주얼 씬 함수 분석 (FT2.exe 모드 8)

날짜: 2026-10-16 · 근거: Ghidra 디컴파일(REA) · 보완: `analysis/save_sound_visual.md` §3(디스패치 표, `vsllst.dat` 레코드). 표기: [관찰] = 디컴파일로 확인, [추정] = 미확인.

`PLAY_VISUAL n` 은 표 0x449598 `(i16 scene, i16 step)[48]` 로 (장면, 시작 부) 를 고르고, `FUN_00401b40` 이 장면 번호로 14개의 손으로 짠 장면 함수 중 하나를 매 프레임 부른다. 장면 함수는 전역 sub-step `DAT_00449664` 로 진행하는 상태 기계다. 웹판은 이 상태 기계들을 타임라인 명령으로 전사한다(`web/src/visual/`).
