# 소리 — 효과음·음악 (하위 프로젝트 5 계획 B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `SOUND`(WAV 16채널 규칙)와 `MUSIC`/`MUSIC_FADE`/`WAIT_MUSIC_FADE`(MIDI → 브라우저 합성)를 `play.html` 에 넣고, 볼륨·음소거와 브라우저 자동재생 정책을 처리한다.

**Architecture:** 순수 상태 기계(`audio/music.ts` 의 페이드·곡 상태, `audio/sound.ts` 의 채널 규칙)를 가짜 오디오/신디사이저로 테스트하고, 브라우저 어댑터(`audio/webAudio.ts`, `audio/spessa.ts`)는 얇게 둔다. `Stage` 가 소리 메서드를 얻고 `GameCore` 의 Host 메서드가 거기에 위임한다. 오디오 컨텍스트는 첫 사용자 클릭에 만든다.

**Tech Stack:** Web Audio API, `spessasynth_lib` 4.3 (Apache-2.0, AudioWorklet) + `spessasynth_core`, GM 사운드폰트 `FluidR3Mono_GM.sf3`(MIT, 13.8 MB, 저장소 밖), Python 변환기.

**Spec:** `docs/superpowers/specs/2026-10-16-save-sound-visual-design.md` §3, §4, §5, §7, §9, §10, §11, §12(계획 B), §14.

## Global Constraints

- 효과음: 채널 16개. 이름 앞 `*` → 채널 0 고정(기존 채널 0 정지), 아니면 첫 빈 채널(없으면 0). 빈 이름 → 채널 0 정지. 없는 파일 → 경고 1회(`analysis/save_sound_visual.md` §2.2).
- 음악: `MUSIC n` → `assets/midi/bgm%02d.mid` 반복 재생 [추정], n < 0 정지, 같은 곡 재시작 금지 [추정]. `MUSIC_FADE ms dir`: 선형 페이드 0↔1, dir 0 끝나면 정지, ms 0 즉시. `WAIT_MUSIC_FADE` 는 페이드 끝까지.
- 오디오 컨텍스트와 워크렛은 사용자 제스처 뒤에만 만든다. 그 전의 `MUSIC` 은 기억했다가 시작한다.
- 사운드폰트는 `web/public/assets/sf2/gm.sf3`(git 무시). 없으면 음악은 로그만 남기고 패널에 안내 한 줄.
- `npm run check` 와 `python3 -I -m unittest discover -s tools -p 'test_*.py'` 가 매 작업 끝에 녹색.

## Review Focus

1. **페이드 아웃 중 새 `MUSIC n`** 이 오면 페이드를 버리고 새 곡을 볼륨 1 로 시작한다(원작 `FUN_0042e8c0` 은 `DAT_0044b75c = 0` 으로 페이드 상태를 지운다). → Task 3 테스트 `a new song cancels a running fade`.
2. **빈 채널이 없을 때의 `SOUND`** 는 채널 0 을 끊고 거기서 재생한다. → Task 2 테스트 `the 17th sound takes channel 0`.
3. **사운드폰트 없음**: `MUSIC` 호출이 예외 없이 로그로 끝나고 효과음은 그대로 난다. → Task 4 테스트 `music without a soundfont logs once and keeps the game running`.
4. **`WAIT_MUSIC_FADE` 가 페이드 없이 호출**되면 즉시 넘어간다. → Task 3 테스트 `fadeBusy is false with no fade`.
5. **탭이 숨겨졌다 돌아올 때** 음악이 이어진다(컨텍스트 `suspended` → `resume()`), 효과음 큐는 쌓이지 않는다. → Task 5 브라우저 확인.

### Task 3: MusicPlayer

**Files:** Create `web/src/audio/music.ts`; Test `web/test/music.test.ts`.

**Interfaces:**
```ts
export interface Synth { ready: boolean; play(song: number, loop: boolean): Promise<void> | void; stop(): void; setGain(v: number): void }
export class MusicPlayer {
  constructor(synth: Synth, log: (kind: 'warn' | 'info', s: string) => void);
  play(n: number): void;         // n < 0 → stop; 같은 곡이면 무시; 페이드 취소, gain = volume
  stop(): void;
  fade(ms: number, on: boolean, now: number): void;   // ms 0 즉시
  fadeBusy(): boolean;
  update(now: number): void;     // 페이드 진행; dir 0 끝 → stop
  volume: number;                // 0..1 (페이드 × 볼륨 = gain)
  readonly current: number;      // −1 없음
}
```
- [ ] **Step 1: 실패하는 테스트**(가짜 Synth 기록) — `play(6)` → synth.play(6, true), gain 1; `play(6)` 다시 → 호출 없음; `play(-1)` → stop; `fade(1000, false, 0)` → `update(500)` gain 0.5, `update(1000)` gain 0 + stop, `fadeBusy` false; `fade(0, true)` 즉시 gain 1; 페이드 중 `play(7)` 은 페이드 취소 + gain 1; `fadeBusy()` 는 페이드 없으면 false; volume 0.5 면 gain 0.5.
- [ ] **Step 2–4: RED → 구현 → check.** **Step 5: 커밋** — `"feat(web): MusicPlayer state machine (song, loop, linear fades)"`
